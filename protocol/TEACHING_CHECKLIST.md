# 教學審閱：用證據判斷，不用空泛評分

按核心概念核對下列事項。每個問題填入具體教程段落或例子、發現的缺口、修正處；不適用時寫原因，不為湊表格新增冗文。封面與來源通知不必套用完整教學模板。

| 檢查 | 需要的證據 |
|---|---|
| 動機與銜接 | 學習者知道問題是什麼、為什麼需要此概念、如何接上前文 |
| 先備、符號與條件 | 使用前已有定義；索引、量詞、模型、適用條件不含糊 |
| 推導與理由 | 關鍵中間步驟沒有省略；直覺、例子與一般證明分清楚 |
| 完整例子 | 可依文字重算／重播；演算法有輸入、中間狀態、選擇理由、停止條件與輸出 |
| 限制與易錯處 | 必要的邊界、失敗情況或常見誤解有具體說明 |
| 理解檢查 | 能只憑教程作答，有答案理由；已有題目不刪減，新增題目按授權處理 |
| 來源與補充 | 原教材內容、作者解釋與未知資訊分清；不虛構頁碼或老師發言 |
| 可獨立閱讀 | 關鍵教學不依賴隱藏MD或臨時Q&A補完 |
| 就近配圖 | 提到來源圖例／表格／程式時，所需整圖或局部圖就在相鄰段落；不用翻到主題末尾或另開PDF才能理解 |

對每個實質缺口先修正內容，再檢查修正是否真的補上推理。沒有固定最低字數，也不能將字數長、標題多、每項自評滿分當成通過。

## 轉製後另查

- 定稿純教程原檔保留，可行時記錄SHA-256。
- 正文、例子、證明、程式與自我檢查有段落到可見區塊的對照。原稿只藏在sources或contextOnly不算可見教程完整。
- 完全隱藏的是逐圖辨識／標記稽核，不是教學推導；每圖解釋與總結不能取代完整教程。
- 裁圖保留必要圖例、標籤與箭頭，能定位回原頁；最終裁圖已實際看過，隱藏詳述只把該範圍內可見的內容當作可見事實。保留完整來源，純文字不無謂截圖。
- 格式驗證、逐圖核對、閱讀DOM、Q&A全文與遠端AI回答各自報告；未做的明說未做。

本清單是作者審閱工具，不代表已做真實學習者測試，也不自動證明AI回答品質。
