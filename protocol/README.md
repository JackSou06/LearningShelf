# LearningShelf AI 作者包（格式1.1／全自動教學優先2026-10-21）

預設收到教材即自動寫教程、教學審閱並修正、轉製ZIP及自檢，不需使用者確認大綱或定稿。三階段是AI內部品質流程，不是三次使用者操作。

- START_HERE.md：一次設定後只提供教材的用法。
- AGENTS.md：專案預設規則；首次把作者包內容放至專案根目錄，與AUTHORING.md同層。不同專案需各自設定一次，不會自動跨專案繼承。
- AUTHORING.md：完整協議。A／A.1先教學，B–J在轉製時使用；仍須完整逐圖辨識、隱藏詳述與Q&A全文。
- PROMPTS/：內部三階段參考，自動串接，不需使用者逐一貼上。
- TEACHING_CHECKLIST.md：具體教學證據檢查，不能用格式驗證代替。
- 兩份Schema及example-course/：格式仍1.1，最低App仍0.2.3（build16），不需更新App功能。範例無圖片，不代表實際教學品質或已完成逐圖核對。
- VALIDATION.json：實際文件與範例檢查，不代表學習者測試或遠端AI答案測試。

作者包不是課程匯入ZIP；AI最後產生的單門課程ZIP才拖入LearningShelf。不修改App、不啟用背景監看、不帶入私人資料。僅在使用者明確要求先確認或只做某階段時，才按要求暫停或限縮。
