# 全自動製作：只提供課程文件

預設直接完成：整理大綱與缺口 → 寫完整純教程 → 自行教學審閱與修正 → 轉製單門課程ZIP → 自檢並交付。不等待使用者批准大綱、樣章或教程，也不要求分三次貼提示詞。

## 同一專案以後只給教材

首次將作者包內容解壓至專案根目錄，讓AGENTS.md與AUTHORING.md在同一層；或在已有規則的專案使用此作者包。之後在該專案提供可讀教材即可，專案規則會說明全自動製作要求。新專案沒有自動繼承其他專案的協議，首次仍須放入作者包或協議。

若不安裝專案規則，首次把作者包ZIP與課件一起交給AI，簡短說：

> 依作者包全自動製作課程，不需中途確認。

已指定定稿教程就保留原稿轉製。只有課件則自行撰寫教程。未知偏好採合理預設；局部來源不清明列待核對，不能編造事實。使用者另有「只寫教程」「先等我確認」指示時，才依其要求停在特定階段。

## AI內部三階段，使用者一次交付

1. 按AUTHORING.md的A／A.1及PROMPTS/01先完成可獨立閱讀的教程，不先套JSON、ID或打包格式。
2. 按TEACHING_CHECKLIST.md及PROMPTS/02，用具體段落、例子與推導審閱並修正，然後自行定稿。
3. 按PROMPTS/03與協議B–J保留全部教學轉製，交付ZIP、純教程、審閱及覆蓋／圖片／實際自檢報告。

理解所需推導、例子與程式步驟保持可見；逐圖辨識與標記稽核的MD完全隱藏但供Q&A讀取。無需修改App。作者包本身不是課程匯入ZIP，最後生成的單門課程ZIP才拖入LearningShelf。

本流程透過專案指令約定工作方式，不是背景監看或上傳事件自動化；AI仍須在收到教材的對話中執行。內容自檢不代表已證明真實學習效果。
