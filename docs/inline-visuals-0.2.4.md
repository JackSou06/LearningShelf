# 就近配圖與來源裁圖（0.2.4 build 18）

製作流程現在要求第一次講到來源圖形時，就把圖片放在該段前後。需要局部圖時，模型規劃原頁與比例範圍，由原生 App 從原件產生 PNG，再啟動內部最終看圖回合。完整來源頁及教材保留；學生仍使用原有 image／markdown 等區塊閱讀，詳述完全隱藏並進入當前主題 Q&A。

## 製作與驗證

1. 教程及審閱辨認需要圖示的段落，避免只寫「見 PDF」。純文字通常直接引用並解釋，不強制截圖。
2. 轉製把圖片放在主要教學區塊旁。IMAGE_MAP.json 的 teachingBlockIds 指向同主題、忽略 contextOnly 後相鄰的教學區塊；來源裁圖另列 sourceImage 與 crop。
3. crop 使用顯示方向原頁左上起算的 x／y／width／height 比例。App 從原 PDF 以較高解析度取出局部，圖片則按顯示方向裁切，輸出唯一 assets PNG。越界、不安全路徑、共享輸出及超出容量會失敗，不偷偷截斷或生成式重畫。
4. App 以 CROP_PREVIEWS.json 列出實際尺寸、來源頁、區域與 SHA256，請 Codex 看最終 PNG 並同步圖說、隱藏 MD 及可見解釋。修改範圍會重產並再次核對，不等待使用者批准。
5. 原生檢查裁圖檔案符合 App 的渲染結果、引用保存的原件與實際頁序、圖文相鄰、所有原頁仍完整保留、每張圖的詳細 MD 全文進入 Q&A；ZIP 封裝後再次比對，通過才自動加入書架。渲染在背景執行，可取消。

範例對照項目（屬作者資料，不是新的閱讀元件）：

```json
{
  "topicId": "self-check",
  "imageBlockId": "ellipse-crop",
  "detailBlockIds": ["ellipse-crop-detail"],
  "teachingBlockIds": ["question-7-answer"],
  "sourceImage": "input/rendered/source-001-page-0002.jpg",
  "crop": {"x": 0.38, "y": 0.32, "width": 0.22, "height": 0.22}
}
```

image 區塊以 file 指向唯一 assets/*.png，references 指回 sources 內的原教材，PDF／PPTX 使用真正頁序。局部圖的隱藏描述要分清「最終裁圖可見」與「原頁其他區域」；不能把裁圖外的公式、標題或註記寫成裁圖中看得到。來源本來沒有的細節不能補畫。

## 本機驗證

`python3 scripts/check_authoring.py` 的新測試使用實際兩頁 PDF 與真正 AppStore／CourseLibrary，但 Codex 是可控制的測試替身。已通過：

- App 先渲染局部 PNG，才要求最終看圖回合，通過後自動安裝。
- 原 PDF 的高解析度渲染、左上比例座標、綠色矩形及留白邊界的像素核對。
- 完整來源頁與教程不變；裁圖、全頁各有同主題隱藏 MD，全文進入 Q&A。
- 改過 PNG 像素、把圖移離教學段落、移除原頁引用、負數／零面積／越界座標、含符號連結的輸出路徑均被拒絕。
- 實際瀏覽器閱讀器檢查三張圖片載入、圖文區塊相鄰、裁圖所在物理頁可顯示，以及三份詳述不進閱讀 DOM 但全文出現在 Q&A 傳送預覽。

原有課程庫／更新保存與 core／contextOnly 檢查也已通過。詳細本機結果在 dist/inline-visual-review/ 及 dist/authoring-review/；生成檔不提交 Git。真正 Codex 的轉製及最終裁圖核對另外執行，與測試替身結果分開記錄。

## 真正 Codex 與閱讀器核對

沿用先前已審閱的合成求和教程，只接續轉製及最終裁圖核對。真正 Codex 在第 7 題旁規劃原 PDF 第 2 頁紅色橢圓的局部，App 產生 845×476 PNG，Codex 實際用圖片工具查看後更新同主題隱藏 MD、圖說及可見解釋，區分裁圖內紅圈與裁圖外的標題、綠色矩形及公式。邊線與白邊完整，未改動裁切範圍。

原生驗證、封裝後複驗及真正 AppStore／CourseLibrary 的隔離書架自動匯入均通過。教程位元組完全不變，八個主題與原有 62 個區塊 ID 全部保留，新增裁圖、隱藏詳述及就近解釋共三個區塊，總數為 65。沒有操作個人書架或宣稱已重製使用者的演算法課程。

Chrome／Playwright 再核對八個主題、三張圖片與三份詳述：圖片可載入、實際 DOM 中的圖文相鄰，所有詳述不出現在閱讀 DOM，但全文出現在所屬主題的 Q&A 傳送預覽。用真正下一頁操作找到局部圖並保存穩定閱讀畫面。原始整頁與 PDF 保留，未用局部圖取代來源。這次沒有重跑第一／第二階段教學生成，也未呼叫遠端 Q&A 模型回答。

## 適用範圍與限制

- 本次改善之後的自動製作與重新轉製規則，沒有自行重寫或重排已匯入的使用者課程。舊課程一般匯入與閱讀方式保持相容，課程 schema 仍為 1.1。更新已有課程須保留 courseId／未變概念 ID 並提高 contentVersion。
- 圖文相鄰只驗證已列出的依賴，不能證明模型已找到所有需要配圖的句子，也不能自動判定裁圖是否保留了每個必要箭頭與圖例；需要視覺審閱。
- 小視窗可能把相鄰區塊排到前後兩個物理頁；沒有承諾任意尺寸都能讓整圖與完整解釋同頁。
- 未呼叫遠端 Q&A 模型測回答，未證明學習效果。原有 PPTX／Keynote 開檔逾時與未驗證項目見 authoring-validation-0.2.4.md；這次沒有宣稱已修好該環境問題。
