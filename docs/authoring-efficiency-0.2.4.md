## 實作

- 從 App 內建最新版協議生成五份階段規則；教程只收到教學與看圖要求，審閱收到教學清單，轉製收到元件及計畫規則。完整協議仍可按節次查閱，不需要每階段重讀。
- 新增原生計畫轉製器：AI 提供教程行範圍、主題／區塊、配圖依賴與完整詳述；App 原樣取出 Markdown，保存來源／定稿／審閱，建立 JSON、hash、覆蓋對照及圖片對照。程式、表格、公式、圖解、題目與互動等全部11種既有區塊保留，能力清單從內建 Schema 生成。
- 製作頁可預先指定「沿用已完成的教程 MD」，需恰好一份 MD；跳過從零寫教程，保留原始位元組，繼續核對、補充及轉製。未指定不會僅憑副檔名猜定稿。
- 原生驗證產生 NATIVE_VALIDATION.md，列檔案、每圖與完整 MD 的實際路徑、各項檢查和限制；不要求模型重寫格式檢查工具及多份機械報告。
- 保存教材準備結果及逐圖最終核對狀態；教材快取使用 App 自己保存的可信清單比對，模型不能靠修改工作目錄 manifest 省略來源頁。修改圖片、圖說、詳述或相關解釋會使對應核對失效。
- 座標改動直接重產並再看圖，不插入一般內容修復回合；服務／連線失敗保留產物退出。缺檔提示只要求續作缺少的產物。
- 接收官方 app-server 用量事件，保存階段、thread／turn、輸入、快取、輸出、其中推理及可取得的快取寫入數；重複事件不重複計數。頁面顯示已記錄用量，不能換算為訂閱費用或保證節省比例。
- 保留所選模型，模型明確支援 medium 時轉製／格式修復使用 medium；教程、實質審閱及最終圖片判讀維持 high。沒有支援資訊的舊工作或測試替身保留原設定。
- image 新增可選 display：寬20–100%、最大高120–800px、左／中／右對齊。新製局部圖預設60%／260px，原頁100%／360px；閱讀器再按頁高限制，保持原比例、不截去像素。點圖以對話框查看原尺寸，Escape 關閉。

## 適用範圍與限制

新計畫用於 App 的新製課程，既有已匯入課程不會被自動重寫；舊工作仍可驗證現有 course/ 產物後續作。這個生成器目前仍建立新 courseId／1.0.0，沒有新增既有課程編輯模式。

固定工具處理資料操作，AI 繼續決定教學內容與視覺安排；全新的互動元件仍需要擴充閱讀器與驗證器。格式驗證不能判定每個推導、圖像辨識或語意配圖依賴都正確。

首次逐圖辨識與新／改版最終裁圖判讀仍須執行；沒有把完整隱藏詳述換成摘要。圖片縮放不保證任意大小視窗下所有長圖與長文都能同頁。display 需要 build19 或支援它的閱讀器，不能假設舊版格式1.1閱讀器都接受新欄位。

沒有呼叫遠端 Q&A 測回答，沒有證明實際學習效果，也尚未以相同教材／相同定稿做嚴格優化前後 A/B；不能承諾節省百分比。PPTX 的既有本機 Keynote 轉換限制仍見原 authoring-validation 文件。

## 真正 Codex 三階段實測

使用兩頁合成求和 PDF，透過已登入的 app-server 真正依序完成教程、審閱、計畫轉製、原生驗證、ZIP 複驗及隔離書架匯入；產生6個主題、4個圖片區塊，沒有自動修復。兩份逐圖 MD 各以 contentFile 在兩個主題重用，由 App 保存完整副本供各主題 Q&A，沒有要求模型重抄詳述；工作目錄未產生 .py／.js／.cjs／.sh 轉製或驗證腳本。

真正 Chrome 逐一核對6個主題、4張圖片、4份隱藏詳述：圖片可載入、圖文相鄰，詳述不建閱讀 DOM，但全文進入實際 Q&A 傳送預覽。此次模型選全頁重用，未自行選裁圖；裁圖路徑另行測試，不把全頁核對冒稱為最終裁圖核對。

用量事件有實際收到，按階段保存於 `dist/optimization-review/live/usage-by-stage.json`。本次定稿與舊測試不同，且舊測試含開發重跑，不能用兩者直接宣稱節省比例。完整流程結果、原生檢查與瀏覽器截圖位於 `dist/optimization-review/live/`。測試教材是合成資料，沒有重製或操作使用者的演算法課程／個人書架。

## 真正 Codex 最終裁圖核對

為覆蓋模型在前次小型教材未選用的裁圖分支，另複製定稿及計畫到隔離工作，加入來源第1頁綠色矩形的局部圖。App 從原 PDF 產生 PNG，真正 Codex 以圖片工具查看後同步圖說、可見解釋及完整隱藏 MD，沒有重跑教程、審閱或轉製規劃；原生檢查、ZIP 複驗及隔離書架匯入通過，零次內容修復。

產物含6主題、5圖片、5份隱藏詳述。此回合記錄6次用量事件、2,359輸出 token（包含197推理 token），未產生轉製／驗證腳本；與過去裁圖不同且對話初始條件不同，不能據此宣稱固定節省比例。真正 Chrome 再核對5張圖及5份詳述均可載入／完整進入實際 Q&A 傳送預覽，裁圖可經下一頁操作找到。沒有呼叫遠端 Q&A。

裁圖輸出、逐圖核對狀態、用量及閱讀器截圖在 `dist/optimization-review/crop-live/`。這是合成教材的工程實測，不是使用者演算法課程的內容驗收。
