# 0.2.4 製課整合驗證（2026-10-21）

已把製作頁面接上本機 Codex app-server 與既有原生課程庫。以下分開記錄真正 Codex、測試替身、本機閱讀器及建置驗證，沒有把結構通過當作教學正確性的證明。

## 真正 Codex 與匯入

使用登入中的 Codex CLI 0.159.0-alpha.12.1，由模型清單選取 gpt-6.1-sol，對兩頁合成 PDF 執行教程、審閱修正、轉製三個階段。原 PDF 為求和公式、綠色矩形與紅色空心橢圓；不含私人的課件或學習紀錄。

教程經審閱後為 281 行，含一般證明、邊界、完整 Python、變數狀態、程式正確性與七題附理由的理解檢查。定稿 SHA-256 為 `8f820bfc70381da87aa2a5f806a89b8f8d46138d4c373312dc542d86c8898165`。轉製成八個主題，保留原 PDF、兩張投影片、兩份同主題隱藏詳述及來源定位。

原生驗證與 ZIP 複驗通過後，由真正 AppStore／CourseLibrary 安裝到隔離書架，並非測試替身宣稱已匯入。既有範例課程仍在，沒有讀寫個人的書架。真正 Codex 的連線、圖片檢視、檔案寫入及三階段生成均已執行。

測試曾因原工具十五分鐘上限中斷，之後也遇到帳號額度限制；兩次都保留教程、審閱及部分轉製檔案，沒有安裝未完成課程。額度恢復後，以相同工作及課程 ID 接續並成功匯入。測試工具現允許四十五分鐘；App 的單階段上限為兩小時。未購買額度，也未使用帳號的重設點數。

## 閱讀與 Q&A

Chrome／Playwright 載入實際生成課程，逐主題操作目錄及「傳送內容」：

- 八個主題可開啟，兩張原投影片都能載入。
- contextOnly 詳述在閱讀 DOM 中不存在，沒有展開入口。
- 兩份詳細 MD 全文都出現在所屬主題實際 Q&A 傳送內容預覽。
- 逐圖記錄文字、位置、顏色、物件、紅圈範圍與不確定性；紅圈只圈空白，不臆測其標記意圖。圖片仍保留，正文有可見解釋。
- 尚未呼叫遠端 Q&A 模型回答問題，不能稱為已驗證回答品質或真實學習效果。

畫面檢查發現大 Markdown 區塊可能把正文推到下一個物理頁，因此內建協議與輸出契約增加自然段落拆分規則。沿用保存的教程重新轉製後，區塊由 49 個增為 62 個，八個主題 ID 與原有全部區塊 ID 均保留，教程雜湊不變。原生驗證、ZIP 複驗、自動匯入及上述瀏覽器檢查再次通過；實際首頁已顯示正文，不再只有標題。這是隔離測試中的轉製重跑，沒有重寫教程或修改個人書架。

原生驗證檢查課程結構、固定識別、來源位元組、定稿雜湊、每個非空教程行的可見區塊引用、每張原圖保留、詳述屬於同主題並進入 CourseCore.context。行覆蓋對照本身不能證明所有語意逐句等價；圖片辨識正確性仍需視覺審閱。

## 未通過或未驗證

- 本機 Keynote 14.1 的 PPTX 自動開檔出現 AppleEvent 逾時，沒有完成 PPTX 端到端驗證；不能聲稱已證實原因是首次設定或授權。App 會保留錯誤與 conversion.log，可處理環境後重試，或先匯出 PDF。
- LibreOffice 分支尚無本機安裝環境可實測。PPTX 中影片、動畫、音效不在靜態投影片轉圖的驗證範圍。
- 真正初次瀏覽器登入流程尚未以未登入帳號端到端測試；已登入帳號的官方 app-server 連線已測，登入事件與工作續作由測試替身驗證。
- 未在 Intel 實機、其他 macOS 版本或大型課件上端到端實測。來源容量、工具與模型用量限制仍適用。
- 此功能先處理新增課程；更新既有課程仍走保留 courseId 並提高 contentVersion 的 ZIP 匯入。
