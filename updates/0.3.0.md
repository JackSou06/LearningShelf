# LearningShelf 0.3.0

2026-10-21 · build22 · macOS 13 或以上 · Apple Silicon／Intel 通用版

本版整合 0.2.3 正式版之後的全部功能更新。開發期間的 0.2.4 build17–21 統一以 0.3.0 發行。

## 在 App 內自動製作課程

- 新增「AI 製作課程」頁面：加入 PDF、PPTX、MD／Markdown、PNG／JPEG／WebP，多份教材可合成一門課。首次設定可用的 Codex CLI 並登入，之後由 App 執行「寫教程 → 教學審閱修正 → 轉製 → 驗證 → 打包 → 加入書架」，不等待逐階段確認。
- 透過官方 Codex app-server 連接本機 CLI，提供登入、可用模型選擇、目前階段、進度訊息、製作紀錄、取消、失敗重試與結果資料夾。關閉製作頁面仍可繼續執行。
- 每次製作自動帶入 App 隨附的最新版《課程明文協議》與 Schema，不需要另傳作者包。
- 可明確指定「沿用已完成的教程 MD」。App 保留原始位元組，跳過從零撰寫，繼續獨立審閱、補充與轉製；不會只因提供 MD 就自行猜定稿。
- 驗證通過後才加入書架，失敗先針對具體問題自動修正；仍未通過時保留工作，不安裝未完成課程。新製作建立新課程 ID；更新既有課程仍使用相同 courseId、提高 contentVersion 的 ZIP／資料夾匯入流程。

## 分階段規則與固定工具

- 教程、審閱、轉製、最終圖片核對及格式修復各收到對應規則；完整協議仍可按需查閱。保留完整教學、逐張看圖、程式演練、例子與自我檢查要求。
- 新增原生計畫轉製：AI 決定教程、主題、區塊與配圖，App 負責來源複製、雜湊、依行範圍原樣取出定稿、JSON、覆蓋表、圖片對照、報告、裁圖、驗證、ZIP 及匯入，不必每門課重新寫工具。
- 保留全部 11 種既有內容區塊，包含程式、表格、公式、圖解、題目與互動演練。固定工具不限制 AI 設計教學內容；全新互動元件仍需閱讀器與驗證器共同支援。
- 教材準備與圖片核對結果可重用。來源、裁圖、圖說、隱藏詳述或相關教學改變時，只使對應核對失效；座標修改會重產並再看最終圖片。服務、連線與額度錯誤會保留產物，不誤當成教材錯誤重寫教程。
- 製作頁保存並顯示可取得的階段用量，區分輸入、快取、輸出及其中推理，重複事件不重複計算；缺少事件代表未知，不解讀為零。轉製／格式修復在模型明確支援時使用 medium，教程、審閱與最終看圖維持 high；不承諾固定節省比例。

## 圖片就近呈現與閱讀版面

- 教程在使用圖示的段落前後放圖並解釋，減少讀者另開 PDF 對照。需要局部內容時，App 從原 PDF／圖片產生裁圖，同時保留完整來源頁、可靠定位與原始教材。
- 裁圖完成後核對最終顯示版本，同步圖說、相關解釋與所屬主題的完整隱藏 MD。新增圖文相鄰引用、裁圖原件、頁序、範圍及詳述對照檢查。
- 圖片可設定寬度 20–100%、最大高度 120–800 px，以及左／中／右對齊。新製局部圖預設寬 60%、高 260 px，原頁預設寬 100%、高 360 px；閱讀器再依頁高限制，保持原比例與全部像素，點圖可放大並用 Escape 關閉。
- 長 Markdown 按自然段落拆分，避免首頁只有標題、正文被整塊推到後頁；不刪減教程內容。
- 延續 0.2.3 的完全隱藏詳述：詳細圖片觀察不建立閱讀 DOM、不進入閱讀搜尋，仍全文加入所屬主題 Q&A、「傳送內容」預覽與完整 MD 匯出。可見正文保留教學解釋與總結。

## 課程容量與失敗續作

- 課程 JSON、Markdown 與圖片合計上限由 20 MB 提高至 **100 MB**，原生載入、瀏覽器匯入、命令列驗證、原生裁圖總量與協議一致更新。ZIP 與解壓後全部檔案各維持 200 MB；單份計畫／裁圖對照 JSON 的 20 MB 保護不變。
- 卡在舊容量限制的工作可於「AI 製作課程 → 製作紀錄」選取原工作，按「重試並接續」。已完成的教程、審閱與轉製會跳過，接續驗證、打包及匯入，不需要重新拖教材或建立新工作。
- 更新保留書架、學習紀錄與 AuthoringJobs。不要刪除 Application Support 中的個人資料；工作續作仍需可用的 Codex 登入環境。

## Q&A 新增 ChatGPT 帳號

- 課程的「AI 設定」可選 **ChatGPT 帳號** 或 **API Key**。按 **Continue with ChatGPT** 在官方瀏覽器頁登入、選工作區並授權使用方案，回 App 選擇帳號實際可用的模型。
- 支援多個帳號／註冊切換、重新登入、取消登入、登出與 ChatGPT 使用量入口。方案資格、可用模型與額度由 OpenAI 決定；製課的 Codex CLI 登入與此 Q&A 授權各自獨立。
- 沿用相同的主題教材、完整隱藏詳述、筆記、歷史問答、新問題、問答保存及取消流程。ChatGPT 使用額度不足時明確提示，**不會自動改用 API Key**。
- ChatGPT 模式等待 Responses 串流的完整完成事件，區分未完成、連線中斷、授權與額度錯誤，不把部分文字當成成功回答。
- Mac 分享到平板時，由 Mac 使用選定的 AI 連線處理並保存；平板不接收金鑰或登入權杖。獨立離線 HTML 維持本次記憶體中的 API Key 方式。

## 修正 API Key 更新後需重填

- 預設「保存在此 Mac，更新 App 後保留」。空白保存沿用原金鑰；取消勾選僅讓新輸入金鑰暫時使用，不再刪除已保存值。只有「清除金鑰」才移除，並嘗試清除舊 Keychain 項目。
- 憑證固定存於 `~/Library/Application Support/LearningShelf/Credentials/`，與 App 安裝路徑、教材及學習紀錄分開；目錄權限 0700、憑證檔 0600，採原子替換，沒有宣稱另有應用層加密。
- 可讀取的舊 Keychain 金鑰會遷移；若需 macOS 授權或讀取失敗會明示，原資料不會被當成空白清除。舊版未保存或已刪除的金鑰無法自動恢復，需再填一次。
- 登入權杖不進入教材、學習紀錄備份、WebView、平板或 AI 提示；設定損壞時阻止請求，避免意外切回 API 計費。

## 驗證及已知限制

- 已完成合成 PDF 的真實 Codex 三階段製課、原生轉製、最終裁圖核對、ZIP 複驗與隔離書架匯入；另以既有失敗工作副本驗證容量提升後續作，沒有重新生成已完成教程。
- 已通過隔離 OAuth／PKCE／state／nonce／JWKS、權杖更新與撤銷、實際本機 Responses 串流、問答上下文、金鑰跨 App 路徑保存、設定介面、課程庫、更新、SQLite／MD、公式／表格及電腦／平板同步回歸。
- **Q&A 的真實 ChatGPT 帳號授權、實際模型回答與額度扣用尚未完成端到端實測**，真實 API Key 也未用於這批測試。帳號符合資格與方案可用性以 OpenAI 回應為準。
- PPTX 需要 Keynote 或 LibreOffice。本機 Keynote 曾發生 AppleEvent 開檔逾時，LibreOffice 分支尚未實機驗證；可先匯出 PDF。影片、音效與動畫不包含在靜態轉圖驗證內。
- 此版不直接接受 SRT／TXT 製課輸入，需先整理成 Markdown。課程容量仍是整門課載入上限，尚未加入圖片按需載入。
- Intel 真機與實體 iPad 操作仍須實機核對；通用編譯不等同兩者已實測。App 使用本機 ad-hoc 簽章，尚未 Apple Developer ID 簽署或公證；GitHub 正式發行不等同 Apple 公證。
- 自動結構、覆蓋與上下文驗證不能保證每處推導、圖片辨識及教學內容都正確；無法辨識與待核對事項仍保留於工作報告或完整詳述。
