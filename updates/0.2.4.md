# LearningShelf 0.2.4

- 新增「AI 製作課程」：拖入 PDF、PPTX、Markdown 或圖片，依序撰寫完整教程、審閱修正、轉製課程；使用 App 內附的協議，不需另傳作者包或逐步確認。
- 透過官方 Codex app-server 連接本機 CLI，支援首次登入、可用模型選擇與製作進度。
- 驗證課程結構、來源、教程覆蓋對照、每張圖片的隱藏 MD 詳述與 Q&A 全文；驗證錯誤自動修正，通過後打包並加入書架。
- 支援取消、失敗重試、已完成階段接續、製作紀錄、教程與結果資料夾；關閉製作頁面仍會繼續執行。
- 製課改為就近配圖；需要局部圖時由 App 從原 PDF／圖片產生 PNG，再自動核對最終裁圖與隱藏詳述。新增裁圖原件、頁序及圖文相鄰引用檢查，保留整頁與未變 ID。
- 自動製作使用新的課程識別，保留原有教材與學習紀錄；ZIP／資料夾的既有更新匯入流程照常提供。

首次需安裝可用 Codex CLI 並登入。PPTX 另需 Keynote 或 LibreOffice；Keynote 可能要求首次設定及 macOS 自動化授權。結構及上下文驗證不能保證每處圖片辨識或教學內容完全正確，未辨識事項會留在教程與製作報告中。

- build21：Q&A 新增 ChatGPT 帳號登入，與 API Key 並存；使用同一份主題上下文、問答紀錄與取消流程。提供帳號／工作區及可用模型選擇，額度不足不會自動使用 API Key。
- 修正金鑰設定的保存行為：預設跨重開與更新保留，空白或暫時使用不再刪除已保存金鑰；固定私人憑證目錄，支援舊 Keychain 遷移與明確讀取錯誤。
