教材庫資料夾管理與閱讀介面更新。

主頁新增資料夾與子資料夾，可依課程、學期和課題整理教材。支援重新命名、多選移動、拖放、自訂排序、釘選、範圍搜尋，以及卡片／列表切換。

刪除教材或資料夾會先移到 App 垃圾桶，可連同子項目還原。永久刪除另行確認，預設保留學習紀錄。移動和重新命名保留筆記、Q&A、作答及閱讀進度；更新相同課程 ID 時保留自訂名稱、分類位置與釘選。

在資料夾中匯入教材可直接歸檔。主頁新增路徑導覽、最近學習與快捷操作，並保存顯示方式與瀏覽位置。既有教材首次升級後位於根目錄，可自行分類。

閱讀器更新字級、留白、色彩及操作提示。寬螢幕可固定目錄、並排寫筆記，學習紀錄改為摘要呈現，測驗明確標示你的選擇與正確答案。

資料夾整理適用於 macOS App 主頁；獨立 HTML 保留教材選擇與閱讀功能。支援 macOS 13 以上、Apple Silicon 與 Intel。
